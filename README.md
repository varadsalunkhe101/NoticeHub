# NoticeHub

## Digital Notice Board Management System

NoticeHub is a web-based application that allows administrators to manage and publish notices digitally while providing students with a dedicated platform to view announcements.

## Features

* Admin Login Authentication
* Add Notices
* View Notices
* Delete Notices
* Student Notice Board
* XML Notice Export
* Session Management

## Technologies Used

* HTML
* CSS
* JavaScript
* PHP
* MySQL
* XML
